Ribbon · SoundCharts tab and SoundCharts Layer contextual tab PROPOSEDCURRENT

Group order follows the brief (§2.1): Data, Display, Time, Inquire, Output, Help. Mariner Settings... becomes the Display group's dialog launcher (Pro's native "more settings" affordance) instead of a lonely small button. The palette split button shows the current palette's icon. Each command has its own icon: no two commands share a glyph. Hatched groups are in the brief but not built yet.

Today: Mariner Settings... sits alone in a fourth column; Day, Dusk, Night and Follow Pro theme share one ColorSelector icon; Object information uses Pro's own Explore icon; About and Scale note share GenericInformation; Add SoundCharts Data and About SoundCharts both have keytip A.
