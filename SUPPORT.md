# Support

Thanks for using SoundCharts for ArcGIS! This page explains where to go
depending on what you need.

## Questions and feedback

For "how do I…?" questions, usage help, ideas and general feedback, open a
[feedback issue](https://github.com/philliphoff/EncDotNet.ArcGIS/issues/new?template=feedback.yml).

Before asking, it can help to check:

- The [README](README.md).
- The [EncDotNet.S100 documentation](https://soundcharts.app/docs/), for the
  S-100 products, portrayal and the `s100` command-line tool.
- Existing [issues](https://github.com/philliphoff/EncDotNet.ArcGIS/issues)
  in case your question has already been answered.

## Bug reports and feature requests

- Found a bug? Open a
  [bug report](https://github.com/philliphoff/EncDotNet.ArcGIS/issues/new?template=bug_report.yml).
- Want a new feature? Open a
  [feature request](https://github.com/philliphoff/EncDotNet.ArcGIS/issues/new?template=feature_request.yml).

When filing an issue, include the add-in and ArcGIS Pro versions (choose
**About SoundCharts** on the **SoundCharts** tab, then **Copy**) and a
minimal way to reproduce. **Never attach real ENC data**: use small synthetic
fixtures or describe the data instead.

A problem with how a chart is portrayed, the same in the SoundCharts desktop
app or the `s100` tool, belongs in
[EncDotNet.S100's issues](https://github.com/philliphoff/EncDotNet.S100/issues).

## Security issues

Please do **not** file security vulnerabilities as public issues. Follow the
private reporting process in [SECURITY.md](SECURITY.md).

## Contributing

Interested in contributing code or docs? See [CONTRIBUTING.md](CONTRIBUTING.md)
